# Case Study — HED Space Desktop

## Challenge

My core background is Java full-stack development. HED Space uses a different stack: Tauri, Rust, SQLite, JavaScript, and mpv.

I used Codex and Hermes to accelerate repository exploration, implementation, debugging, review, and UI iteration while I retained responsibility for requirements, scope, runtime validation, and acceptance.

## What the case study proves

The useful skill is not “AI wrote code.” It is the ability to become productive in an unfamiliar system by combining:

- clear outcome definition;
- repository orientation;
- evidence-first diagnosis;
- focused agent-generated patches;
- screenshot/runtime feedback;
- automated source validation;
- final diff review;
- human-controlled acceptance and publishing.

## Workflow

1. Inspect the repository and locate relevant components.
2. Trace current behavior before changing code.
3. Give the agent a constrained task with explicit completion criteria.
4. Implement the smallest useful patch.
5. Run source checks and Windows runtime verification.
6. Review the diff and iterate using focused follow-ups.
7. Publish only after the behavior is verified.

## Result

The resulting project is a working Windows desktop media library with local scanning, SQLite metadata/progress, Tauri UI, mpv playback, and a custom cinematic interface.

The project is published as an **AI-assisted engineering case study**, not as a claim that Rust/Tauri is my primary specialization.

# Implement a feature

```text
Goal:
Implement [feature].

Context:
- Start with [relevant files/components].
- Current behavior: [behavior].

Boundaries:
- Preserve unrelated public behavior.
- Keep the diff focused.
- Do not add a production dependency without explaining the need first.
- Preserve unrelated working-tree changes.

Verification:
- Exercise [acceptance scenario].
- Run the narrowest checks that give strong confidence, then broader affected checks if useful.

Deliverable:
Implement the feature, review the final diff, and summarize files changed,
commands/checks run, outcomes, and any remaining risk.
```
